# Changelog

## v0.1.0
- First release: host preparation (`scripts/host-prep.sh`), qualification (`scripts/qualify.sh`), optional
  boot-time volume unlock (`scripts/volume-unlock.sh`, with `scripts/keychain-add.sh` to store its passphrase in
  the System keychain), one strict config file for every site-specific value,
  design, runbook, pitfalls from a real install on macOS 27, an example iOS workflow, and offline unit tests.
